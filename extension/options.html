chainscope

Connects to a store served on this machine. Nothing leaves it.

Start the server with chainscope-serve --writable. It prints a fresh token each run and binds to loopback only.

The token is not decoration. Any page you have open can make requests to 127.0.0.1 — binding to loopback keeps other machines out and does nothing about this one. Without the token, every request is refused.
